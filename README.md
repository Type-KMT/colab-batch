# colab-batch

colab-batch is a personal, single-user automation tool. It lets its owner manage their own Google Colaboratory runtimes programmatically through the official Colab API — for example, starting a runtime, running batch jobs on it, retrieving the results, and shutting the runtime down when finished.

- **Users:** The app is used by its owner only. It is not offered to the public and has no sign-up.
- **Data accessed:** Only the owner's own Google Colab resources, using the `colaboratory` OAuth scope.
- **Purpose:** Running the owner's own batch workloads on the owner's own Colab subscription.
