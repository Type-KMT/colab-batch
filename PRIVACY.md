# Privacy Policy — colab-batch

Last updated: 2026-11-26

colab-batch is a personal tool operated by its owner, for their own use only.

## What data the app accesses

With the owner's authorization, the app accesses the owner's own Google Colaboratory resources through the Google Colab API, using only this OAuth scope:

- `https://www.googleapis.com/auth/colaboratory`

This allows the app to list, create, run code on, and delete Colab runtimes that belong to the owner.

## How the data is used

The access is used solely to automate the owner's own Colab sessions: starting runtimes, executing the owner's own batch jobs, retrieving the resulting files, and stopping runtimes. The app does not access data belonging to any other person.

## Storage and sharing

- OAuth tokens are stored locally on the owner's own computer, in a file readable only by the owner.
- No user data is sold, rented, or shared with third parties.
- No user data is used for advertising or analytics.

## Revoking access

The owner can revoke the app's access at any time from their Google Account security settings (third-party access). Revoking access immediately stops the app from using the API.

## Contact

Questions about this policy can be sent to the user support email shown on the app's Google consent screen.
